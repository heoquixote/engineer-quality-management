# Learners School : 품질경영기사

품질경영기사를 준비하는 학습자가 시험 합격과 실무 이해를 함께 가져갈 수 있도록 구성한 위키독스용 원고 저장소입니다.  
암기 위주 정리보다 "왜 이 개념이 필요한지", "어디서 계산이 틀리는지", "현업 품질관리와 어떻게 연결되는지"를 설명하는 방향으로 구성합니다.

## 기준 정보

2026년 4월 21일 확인 기준, Q-Net에서 확인 가능한 품질경영기사 출제기준 유효기간은 `2023.1.1.~2026.12.31.`입니다.

- 필기: 실험계획법, 통계적품질관리, 생산시스템, 신뢰성관리, 품질경영
- 실기: 품질경영 실무
- 필기 방식: 객관식 4지 택일형, 과목당 20문항, 과목당 30분
- 실기 방식: 필답형 3시간, 100점
- 합격 기준: 필기 과목당 40점 이상 + 전과목 평균 60점 이상, 실기 60점 이상

## 이 책이 다루는 것

- 품질경영기사 시험 구조와 과목별 학습 전략
- 품질경영 기본 개념, 품질비용, QC 7가지 도구, 개선 체계
- 통계적 품질관리, 관리도, 공정능력, 샘플링 검사
- 실험계획법, 분산분석, 직교배열, 교호작용 해석
- 생산계획, 재고관리, 공정배치, 일정계획, Lean 관점
- 신뢰도, 고장분포, MTBF, 가용도, FMEA/FTA
- 실기형 서술 문제와 계산 문제를 푸는 답안 작성 구조

## 이런 분께 적합합니다

- 품질경영기사를 처음 준비하는 분
- 산업공학, 생산관리, 품질 직무와 시험을 함께 연결해서 이해하고 싶은 분
- 통계는 배웠지만 관리도, 실험계획법, 신뢰도에서 자주 막히는 분
- 단순 요약집보다 구조화된 설명과 실무 맥락이 필요한 분

## 학습 목표

이 책을 마치면 다음 내용을 스스로 설명하고 적용할 수 있습니다.

- 각 과목의 핵심 범위를 시험 관점과 실무 관점으로 구분하기
- 관리도 종류를 상황에 맞게 선택하고 해석하기
- 공정능력지수, 신뢰도 지표, 실험계획 결과를 계산하고 해석하기
- 생산성과 품질 지표가 서로 어떻게 충돌하거나 정렬되는지 이해하기
- 서술형 실기 답안을 논리적으로 구성하기

## 도서 구성

### 제1부 통계적 품질관리

확률과 확률분포, 검정과 추정, 상관 및 단순회귀, 샘플링검사, 관리도를 중심으로 품질 데이터 해석의 기초를 다룹니다.  
시험에서도 계산 비중이 크고, 실무에서도 공정을 숫자로 읽는 핵심 파트입니다.

### 제2부 실험계획법

실험계획의 기본원리부터 요인실험, 분산분석, 직교배열표, 다구찌 방법까지 연결합니다.  
원인 분석과 조건 최적화를 구조적으로 이해하는 장입니다.

### 제3부 신뢰성관리

신뢰성의 기초개념, 수명분포, 신뢰성시험, 시스템 신뢰도, FMEA와 FTA를 다룹니다.  
시간 축에서 품질을 해석하고 설계 및 유지보전과 연결하는 파트입니다.

### 제4부 생산시스템

생산전략, 자재관리, 생산계획, 표준작업, 설비보전을 중심으로 생산 운영 전반을 정리합니다.  
품질이 생산성, 납기, 재고, 설비 운영과 어떻게 연결되는지 이해하는 장입니다.

### 제5부 품질경영

품질경영의 개념, 품질전략, 표준화, 6시그마, 품질혁신활동을 다룹니다.  
전사적 품질경영 관점과 개선 활동의 프레임을 정리하는 장입니다.

상세 목차는 [TOC.md](./TOC.md)에서 확인할 수 있습니다.

## 저장소 구조

```text
engineer-quality-management/
├─ README.md
├─ TOC.md
├─ pages/
├─ assets/
└─ examples/
```

- `TOC.md`: 전체 목차 관리
- `pages/`: 위키독스 본문 원고
- `assets/`: 이미지와 도표 자산
- `examples/`: 계산 예제, 표, 보조 자료

## 집필 원칙

1. 각 장은 "개념 -> 계산 원리 -> 해석 -> 실무 연결 -> 자주 틀리는 포인트" 순서로 씁니다.
2. 수식은 암기보다 의미와 해석을 우선 설명합니다.
3. 실기형 서술 문장은 바로 가져다 쓸 수 있도록 문장 단위로 정리합니다.
4. 필요하면 표, 예제, 비교 프레임을 넣어 재사용 가능한 원고로 작성합니다.

## 위키독스 운영 메모

1. `TOC.md`에서 전체 목차 구조를 관리합니다.
2. `pages/` 디렉토리에 본문 원고를 추가합니다.
3. 변경사항을 push하면 위키독스 반영 흐름과 연결해 운영할 수 있습니다.
4. 이미지는 `assets/` 디렉토리에 저장하고 상대 경로로 참조합니다.
