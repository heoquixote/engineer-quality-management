# 제5부 품질경영

품질경영은 품질을 검사 활동이 아니라 조직 운영 시스템으로 보는 관점입니다.  
이 파트에서는 품질경영의 개념, 표준화, 6시그마, 혁신활동까지 시험 구조에 맞춰 정리합니다.

<a id="p5-c1"></a>
## 제1장 품질경영과 품질비용

품질경영의 전체 프레임과 고객 관점, 비용 관점을 함께 이해하는 장입니다.

<a id="p5-c1-s1"></a>
### 1.1 품질경영의 개념

품질경영은 고객 요구를 충족하기 위해 조직 전반의 프로세스를 체계적으로 운영하는 활동입니다.

<a id="p5-c1-s2"></a>
### 1.2 품질전략과 TQM

TQM은 전사적 참여를 바탕으로 지속적인 품질개선을 추구하는 대표 전략입니다.

<a id="p5-c1-s3"></a>
### 1.3 고객만족과 품질경영

품질은 내부 규격 충족만이 아니라 고객 기대와 사용 경험까지 함께 고려해야 합니다.

<a id="p5-c1-s4"></a>
### 1.4 품질경영시스템과 협력업체관리

품질경영시스템은 내부 프로세스뿐 아니라 공급자와 협력업체 관리까지 포함합니다.

<a id="p5-c1-s5"></a>
### 1.5 제조물책임과 품질보증

제조물책임과 품질보증은 품질문제를 법적 책임과 고객 신뢰 관점에서 다루게 합니다.

<a id="p5-c1-s6"></a>
### 1.6 교육훈련과 모티베이션

품질 수준은 제도만으로 유지되지 않으며 교육훈련과 동기부여가 함께 작동해야 합니다.

<a id="p5-c1-s7"></a>
### 1.7 서비스업의 품질관리

서비스 품질은 무형성, 동시성, 고객접점 특성을 고려해 별도로 접근해야 합니다.

<a id="p5-c1-s8"></a>
### 1.8 품질비용

예방비용, 평가비용, 실패비용 구조를 통해 총품질비용을 해석하는 관점을 정리합니다.

<a id="p5-c2"></a>
## 제2장 산업표준화

표준화는 품질의 재현성과 일관성을 확보하기 위한 핵심 기반입니다.

<a id="p5-c2-s1"></a>
### 2.1 표준화와 표준화 요소

표준화의 목적과 대상, 그리고 표준이 갖추어야 할 기본 요소를 설명합니다.

<a id="p5-c2-s2"></a>
### 2.2 사내표준화

사내표준화는 작업과 품질 수준을 조직 내부에서 일관되게 유지하는 장치입니다.

<a id="p5-c2-s3"></a>
### 2.3 산업표준화와 국제표준화

국가표준과 국제표준 체계를 비교하면서 품질경영의 대외 기준을 이해합니다.

<a id="p5-c2-s4"></a>
### 2.4 품질인증제도

품질인증제도는 일정 기준을 만족하는 시스템과 제품을 제도적으로 보증하는 방식입니다.

<a id="p5-c3"></a>
## 제3장 6시그마와 품질혁신활동

데이터 기반 품질개선 활동과 측정·분석 체계를 연결하는 장입니다.

<a id="p5-c3-s1"></a>
### 3.1 공정과 공정능력분석

공정능력분석은 공정이 규격을 만족할 잠재력과 실제 성능을 수치로 평가하는 과정입니다.

<a id="p5-c3-s2"></a>
### 3.2 6시그마 혁신활동

DMAIC 중심의 6시그마는 변동 축소와 고객 요구 충족을 위한 대표 혁신 체계입니다.

<a id="p5-c3-s3"></a>
### 3.3 검사설비관리

검사설비의 정확도와 유지 상태는 판정 신뢰성과 직접 연결됩니다.

<a id="p5-c3-s4"></a>
### 3.4 측정시스템

측정시스템은 데이터 품질의 출발점이며, MSA 관점에서 변동과 신뢰성을 평가해야 합니다.

<a id="p5-c4"></a>
## 제4장 품질개선·혁신

품질개선은 단발성 조치가 아니라 지속적인 혁신 시스템으로 접근해야 합니다.

<a id="p5-c4-s1"></a>
### 4.1 혁신활동과 개선활동

혁신활동과 개선활동은 범위와 속도는 다르지만 모두 품질 수준 향상을 목표로 합니다.

<a id="p5-c4-s2"></a>
### 4.2 품질관리수법

QC 7가지 도구와 신 QC 도구를 포함한 다양한 품질관리수법의 목적과 활용 흐름을 정리합니다.
