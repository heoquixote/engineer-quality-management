# 제3부 신뢰성관리

신뢰성관리는 제품과 시스템의 품질을 시간 축에서 해석하는 분야입니다.  
이 파트에서는 신뢰성의 기본 개념, 수명분포, 시험과 추정, 시스템 신뢰도, 설계와 관리 기법을 연결해서 다룹니다.

<a id="p3-c1"></a>
## 제1장 신뢰성의 개념

신뢰성관리의 계산과 해석은 기초 함수와 척도 개념을 정확히 잡는 것에서 시작합니다.

<a id="p3-c1-s1"></a>
### 1.1 신뢰성의 기초개념

신뢰성은 주어진 조건에서 일정 시간 동안 요구 기능을 수행할 확률로 이해합니다.

<a id="p3-c1-s2"></a>
### 1.2 신뢰도함수

신뢰도함수는 시간 경과에 따라 제품이 고장 없이 동작할 확률을 나타냅니다.

<a id="p3-c1-s3"></a>
### 1.3 신뢰성 수명분포

지수분포, 와이블분포 등 수명분포는 고장 메커니즘과 수명 특성을 해석하는 핵심 도구입니다.

<a id="p3-c1-s4"></a>
### 1.4 신뢰성 척도의 계산

MTTF, MTBF, 고장률 등 대표 척도를 계산하고 각각의 의미를 구분해야 합니다.

<a id="p3-c1-s5"></a>
### 1.5 보전성(Maintainability)

보전성은 고장 후 얼마나 신속하게 복구 가능한지를 설명하는 유지보전 관점의 척도입니다.

<a id="p3-c1-s6"></a>
### 1.6 유용성(가용성)(Availability)

가용성은 고장 빈도와 수리 시간을 함께 반영해 실제 사용 가능성을 나타냅니다.

<a id="p3-c2"></a>
## 제2장 신뢰성시험과 추정

실제 데이터와 시험 결과를 통해 신뢰성을 추정하는 방법을 다룹니다.

<a id="p3-c2-s1"></a>
### 2.1 고장률 곡선

욕조곡선은 초기고장기, 우발고장기, 마모고장기로 나누어 고장 특성을 설명합니다.

<a id="p3-c2-s2"></a>
### 2.2 신뢰성 데이터 분석

검열자료와 고장자료를 어떻게 정리하고 해석할지 신뢰성 데이터 분석 절차를 정리합니다.

<a id="p3-c2-s3"></a>
### 2.3 확률모형을 통한 신뢰성추정

표본 데이터를 확률모형에 맞추어 모수와 신뢰도를 추정하는 과정을 설명합니다.

<a id="p3-c2-s4"></a>
### 2.4 가속수명시험

짧은 시간 안에 수명 정보를 얻기 위해 스트레스를 높여 수행하는 시험 방법을 다룹니다.

<a id="p3-c2-s5"></a>
### 2.5 신뢰성 샘플링기법

제한된 표본으로 합격 여부를 판정하는 신뢰성 샘플링의 기본 구조를 정리합니다.

<a id="p3-c2-s6"></a>
### 2.6 간섭이론과 안전계수

하중과 강도의 분포를 비교해 파손 위험을 해석하는 간섭이론과 안전계수 개념을 설명합니다.

<a id="p3-c3"></a>
## 제3장 시스템의 신뢰도

복수 부품과 모듈로 구성된 시스템의 신뢰도는 결합 구조에 따라 달라집니다.

<a id="p3-c3-s1"></a>
### 3.1 직렬결합시스템의 신뢰도

직렬구조는 하나의 구성요소만 고장 나도 전체 기능이 멈추므로 전체 신뢰도가 낮아지기 쉽습니다.

<a id="p3-c3-s2"></a>
### 3.2 병렬결합시스템의 신뢰도

병렬구조는 중복 설계를 통해 시스템 신뢰도를 높일 수 있는 대표 구조입니다.

<a id="p3-c3-s3"></a>
### 3.3 기타 결합시스템의 신뢰도

직병렬 혼합구조와 대기중복 등 다양한 결합 형태의 신뢰도 계산 개념을 정리합니다.

<a id="p3-c4"></a>
## 제4장 신뢰성 설계 및 관리

신뢰성은 시험만으로 확보되는 것이 아니라 설계와 운영 관리 전반에서 만들어집니다.

<a id="p3-c4-s1"></a>
### 4.1 신뢰성 설계

부품 선택, 여유 설계, 중복 설계 같은 신뢰성 설계 전략을 설명합니다.

<a id="p3-c4-s2"></a>
### 4.2 FMEA에 의한 고장해석

FMEA는 잠재 고장형태와 영향을 사전에 분석해 우선순위를 정하는 예방 도구입니다.

<a id="p3-c4-s3"></a>
### 4.3 FTA에 의한 고장해석

FTA는 상위 고장사건을 원인 트리로 분해해 구조적으로 고장 원인을 찾는 방법입니다.

<a id="p3-c4-s4"></a>
### 4.4 신뢰성 관리

시험, 설계, 보전, 데이터 피드백을 연결해 신뢰성을 지속적으로 개선하는 체계를 정리합니다.
