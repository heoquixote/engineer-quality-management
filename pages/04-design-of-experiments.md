# 제2부 실험계획법

실험계획법은 변동의 원인을 체계적으로 분리하고, 최적 조건을 찾기 위한 분석 프레임입니다.  
이 파트에서는 기본 원리부터 요인실험, 여러 실험배치, 직교배열과 다구찌 방법까지 흐름대로 정리합니다.

<a id="p2-c1"></a>
## 제1장 실험계획의 개념

실험계획의 목적과 기본 설계 원리를 먼저 이해해야 이후 배치법과 분산분석을 제대로 해석할 수 있습니다.

<a id="p2-c1-s1"></a>
### 1.1 실험계획의 개념 및 기본원리

반복, 랜덤화, 블록화는 실험계획의 가장 기본적인 세 원리이며 오차를 통제하는 핵심 장치입니다.

<a id="p2-c1-s2"></a>
### 1.2 실험계획의 구조 모형과 분류

실험의 목적과 요인 구조에 따라 완전요인, 일부실시, 분할법 등 다양한 실험 모형으로 나뉩니다.

<a id="p2-c2"></a>
## 제2장 요인실험법

요인실험법은 여러 조건 변화가 결과에 미치는 영향을 동시에 파악하는 대표적인 실험 구조입니다.

<a id="p2-c2-s1"></a>
### 2.1 1요인실험

하나의 요인만 변화시키는 가장 기본적인 실험으로, 집단 간 평균 차이를 비교하는 출발점입니다.

<a id="p2-c2-s2"></a>
### 2.2 반복이 없는 2요인실험(모수모형)

두 요인을 동시에 고려하지만 반복이 없는 경우, 요인 효과와 오차 해석이 어떻게 달라지는지 설명합니다.

<a id="p2-c2-s3"></a>
### 2.3 난괴법

불균질한 실험 환경에서 블록을 설정해 오차를 줄이는 대표 설계인 난괴법을 다룹니다.

<a id="p2-c2-s4"></a>
### 2.4 반복이 있는 2요인실험

반복이 있는 경우 교호작용과 오차항을 더 안정적으로 추정할 수 있으며 분산분석 해석력이 높아집니다.

<a id="p2-c2-s5"></a>
### 2.5 다요인실험

세 개 이상의 요인이 동시에 작용할 때 주효과와 교호작용을 어떻게 해석할지 정리합니다.

<a id="p2-c3"></a>
## 제3장 여러 가지 실험계획법

현장 제약에 따라 다양한 배치법과 특수 분석기법이 필요해집니다.

<a id="p2-c3-s1"></a>
### 3.1 대비와 직교분해

집단 간 차이를 의미 있는 비교식으로 나누어 해석하는 대비와 직교분해 개념을 설명합니다.

<a id="p2-c3-s2"></a>
### 3.2 계수값 데이터의 분석 및 해석

불량수나 발생빈도처럼 계수값 데이터에 적합한 실험분석 방법을 정리합니다.

<a id="p2-c3-s3"></a>
### 3.3 단일분할법

실험 단위가 계층적으로 나뉘는 상황에서 오차구조를 고려하는 단일분할법의 기본을 설명합니다.

<a id="p2-c3-s4"></a>
### 3.4 지분실험법

토지, 시간, 설비 제약처럼 실험 단위의 분할이 필요한 경우 지분실험법을 활용합니다.

<a id="p2-c3-s5"></a>
### 3.5 라틴방격법 및 그레코 라틴방격

두 개 이상 교란요인을 통제하면서 실험효율을 높이는 라틴방격 계열 설계를 다룹니다.

<a id="p2-c4"></a>
## 제4장 요인실험과 직교배열표

복잡한 요인 구조를 효율적으로 설계하고 해석하는 실제적인 방법들을 정리합니다.

<a id="p2-c4-s1"></a>
### 4.1 2^n형 요인실험

두 수준 요인실험은 효과 계산이 명확해 실험계획법의 핵심 출발점이 됩니다.

<a id="p2-c4-s2"></a>
### 4.2 교락법과 일부실시법

실험 횟수를 줄이기 위해 일부 효과를 희생하거나 부분만 수행하는 전략을 설명합니다.

<a id="p2-c4-s3"></a>
### 4.3 직교배열표

직교배열표는 적은 실험으로도 여러 요인의 효과를 균형 있게 추정하도록 설계된 표입니다.

<a id="p2-c4-s4"></a>
### 4.4 회귀분석

실험 결과를 회귀식으로 표현하면 조건 변화에 따른 반응 예측과 최적화가 쉬워집니다.

<a id="p2-c4-s5"></a>
### 4.5 다구찌 실험계획법

강건설계 관점에서 잡음요인을 통제하고 품질손실을 줄이는 다구찌 방법을 정리합니다.
