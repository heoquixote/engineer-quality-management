# 제1부 통계적 품질관리

통계적 품질관리는 품질 데이터를 해석하고, 공정 변동을 이해하며, 합리적으로 판정하는 데 필요한 기본 도구를 다룹니다.  
이 파트에서는 확률과 분포, 검정과 추정, 상관과 회귀, 샘플링검사, 관리도를 하나의 흐름으로 연결합니다.

<a id="p1-c1"></a>
## 제1장 확률과 확률분포

품질 데이터를 다루기 위한 가장 기초적인 언어가 확률과 확률분포입니다.

<a id="p1-c1-s1"></a>
### 1.1 모수와 통계량

모수와 통계량은 통계를 공부할 때 가장 먼저 잡아야 하는 핵심 개념입니다.  
처음에는 이름이 어렵게 느껴지지만, 생각보다 아주 단순합니다.

- `모수`: 전체 집단의 진짜 모습
- `통계량`: 전체를 다 볼 수 없을 때, 일부를 보고 계산한 값

예를 들어 전국 중학생의 평균 키를 알고 싶다고 가정해 보겠습니다.

- 전국 중학생 전부의 평균 키는 `모수`입니다.
- 실제로는 전부를 조사하기 어려우니, 몇 개 학교 학생만 조사해서 평균을 구할 수 있습니다.
- 이렇게 표본으로 계산한 평균은 `통계량`입니다.

쉽게 말하면,

- 모수는 `전체 정답`
- 통계량은 `정답을 짐작하게 해 주는 힌트`

라고 생각하시면 됩니다.

이 절에서는 모수와 통계량을 이해하기 전에 먼저 통계가 왜 필요한지, 데이터가 어떻게 나뉘는지, 평균과 분산이 왜 중요한지까지 한 번에 정리하겠습니다.

#### 1. 통계와 데이터

통계는 단순히 숫자를 계산하는 기술이 아닙니다.  
많은 정보 속에서 규칙을 찾고, 지금 보이는 일부 정보를 바탕으로 전체를 이해하려는 사고 방법입니다.

예를 들어 다음과 같은 질문을 떠올려 보겠습니다.

- 우리 반에서 가장 많은 시험 점수 구간은 어디일까?
- 올해 생산된 제품의 평균 무게는 얼마일까?
- 뽑아 본 몇 개의 제품 품질을 보고 전체 생산품이 괜찮다고 말할 수 있을까?

이런 질문에 답하려면 데이터를 모으고, 정리하고, 비교하고, 해석해야 합니다.  
바로 그 일을 하는 학문이 통계학입니다.

##### 1-1. 통계학의 등장과 분류

사람은 오래전부터 "전체를 다 보기 어렵기 때문에 일부를 보고 판단"해야 했습니다.  
나라의 인구를 파악하거나, 군량미를 계산하거나, 병이 얼마나 퍼졌는지를 알아야 했기 때문입니다.

그래서 통계학은 원래 `숫자를 모아 현실을 이해하려는 필요`에서 등장했습니다.  
지금은 공장 품질관리, 스포츠 기록, 여론조사, 병원 검사, 인공지능 데이터 분석까지 거의 모든 분야에서 쓰입니다.

통계학은 크게 두 가지로 나눌 수 있습니다.

###### 기술통계학

기술통계학은 이미 가지고 있는 데이터를 `보기 쉽게 정리`하는 통계입니다.

예를 들면 다음과 같습니다.

- 평균 점수는 몇 점인가?
- 가장 자주 나온 키 구간은 어디인가?
- 점수 차이가 큰가, 작은가?

즉, 있는 데이터를 `설명`하는 통계입니다.

###### 추측 통계학

추측 통계학은 일부 데이터를 보고 `전체를 짐작`하는 통계입니다.

예를 들면 다음과 같습니다.

- 100명만 조사했는데, 전체 학생의 평균 키도 비슷할까?
- 제품 몇 개를 검사했는데, 전체 lot도 양품이라고 볼 수 있을까?

즉, 표본을 이용해 모집단을 `추정`하거나 `판정`하는 통계입니다.

아주 간단히 정리하면 다음과 같습니다.

- 기술통계학: `지금 가진 데이터를 잘 설명하는 것`
- 추측 통계학: `일부 데이터를 보고 전체를 판단하는 것`

##### 1-2. 데이터 분류

데이터는 크게 `정성적 데이터`와 `정량적 데이터`로 나눕니다.

###### 정성적 데이터

정성적 데이터는 숫자로 재더라도 본질은 `종류`나 `구분`에 의미가 있는 데이터입니다.

예를 들면 다음과 같습니다.

- 혈액형
- 제품 색상
- 고객 만족 등급

정성적 데이터는 다시 두 가지로 나뉩니다.

`명목 데이터`

단순히 이름표처럼 구분만 하는 데이터입니다.

- 남 / 여
- 합격 / 불합격
- 빨강 / 파랑 / 초록

이 데이터는 순서가 없습니다.  
빨강이 파랑보다 크다고 말할 수는 없습니다.

`순위 데이터`

크기나 순서는 있지만, 간격이 정확히 같다고 볼 수는 없는 데이터입니다.

- 매우 만족 / 만족 / 보통 / 불만
- 1등 / 2등 / 3등

순서는 있지만, 1등과 2등 차이가 2등과 3등 차이와 꼭 같다고 할 수는 없습니다.

###### 정량적 데이터

정량적 데이터는 실제로 `수의 크기`에 의미가 있는 데이터입니다.

예를 들면 다음과 같습니다.

- 키 160cm
- 무게 52kg
- 생산 수량 120개

정량적 데이터도 다시 두 가지로 나눕니다.

`이산형 데이터`

뚝뚝 끊어지는 데이터입니다.  
보통 `개수`를 셀 때 많이 나옵니다.

- 불량품 3개
- 형제자매 2명
- 주문 건수 15건

중간에 3.4개 같은 값은 보통 나오지 않습니다.

`연속형 데이터`

이어져 있는 데이터입니다.  
보통 `길이, 시간, 무게, 온도`처럼 측정하는 값에서 많이 나옵니다.

- 172.4cm
- 36.5도
- 12.83초

이론적으로는 아주 작은 단위까지 계속 나눌 수 있습니다.

정리하면 다음과 같습니다.

- 정성적 데이터: 종류를 나타내는 데이터
- 명목 데이터: 순서 없는 분류 데이터
- 순위 데이터: 순서는 있지만 간격 의미가 약한 데이터
- 정량적 데이터: 숫자 크기에 의미가 있는 데이터
- 이산형 데이터: 셀 수 있는 데이터
- 연속형 데이터: 잴 수 있는 데이터

#### 2. 통계적 사고

통계적 사고란 숫자를 계산만 하는 것이 아니라, `이 숫자가 무엇을 뜻하는지`를 생각하는 습관입니다.

예를 들어 평균 점수가 70점이라고 해도 다음 질문을 같이 해야 합니다.

- 모두가 70점 근처였을까?
- 어떤 학생은 100점, 어떤 학생은 40점이었을까?
- 10명 평균인가, 1000명 평균인가?

즉, 통계에서는 숫자 하나만 보는 것이 아니라 `숫자가 만들어진 과정`과 `숫자의 의미`를 함께 봐야 합니다.

##### 2-1. 모수와 통계량

여기서 다시 모수와 통계량을 정확히 정리하겠습니다.

###### 모수

모수는 모집단 전체의 성질을 나타내는 값입니다.

예를 들면 다음이 모수입니다.

- 전국 중학생 전체의 평균 키
- 어떤 공장에서 오늘 생산한 제품 전체의 평균 길이
- 한 lot 전체의 불량률

보통 모수는 그리스 문자로 많이 씁니다.

- 모집단 평균: `mu`
- 모집단 분산: `sigma^2`
- 모집단 표준편차: `sigma`

###### 통계량

통계량은 표본에서 계산한 값입니다.

예를 들면 다음과 같습니다.

- 조사한 100명의 평균 키
- 검사한 20개 제품의 평균 길이
- 뽑아 본 50개 중 불량률

보통 통계량은 영어 문자로 많이 씁니다.

- 표본평균: `x-bar`
- 표본분산: `s^2`
- 표본표준편차: `s`

핵심은 이것입니다.

- 모수는 `전체의 진짜 값`
- 통계량은 `표본으로 계산한 값`
- 우리는 통계량으로 모수를 추정합니다

즉, 통계학은 `일부를 보고 전체를 이해하려는 학문`이라고 할 수 있습니다.

##### 2-2. 통계분석의 과정

통계분석은 보통 다음 순서로 진행됩니다.

###### 1. 질문을 정합니다

무엇을 알고 싶은지 먼저 분명해야 합니다.

- 평균이 궁금한가?
- 차이가 있는지 궁금한가?
- 불량률이 기준보다 낮은지 궁금한가?

###### 2. 데이터를 모읍니다

필요한 데이터를 정하고 조사하거나 측정합니다.

- 학생 키를 잰다
- 제품 길이를 측정한다
- 고객 만족도를 조사한다

###### 3. 데이터를 정리합니다

표로 만들고, 같은 종류끼리 묶고, 이상한 값이 없는지 확인합니다.

###### 4. 숫자로 요약합니다

평균, 중위수, 표준편차, 비율 같은 값으로 데이터를 간단히 요약합니다.

###### 5. 해석하고 판단합니다

숫자를 보고 결론을 내립니다.

- 평균은 높지만 차이가 매우 크다
- 불량률은 낮지만 변동이 크다
- 일부 표본만 봐도 전체가 기준을 벗어날 가능성이 있다

즉, 통계분석은

`질문 -> 데이터 수집 -> 정리 -> 계산 -> 해석`

의 흐름이라고 기억하시면 됩니다.

#### 3. 중심위치의 척도

중심위치의 척도는 데이터가 `어디쯤 모여 있는지`를 알려 주는 값입니다.  
쉽게 말하면 "대표값"입니다.

예를 들어 시험 점수 60, 70, 70, 80, 90이 있다면  
"이 점수들은 대체로 어느 정도 수준인가?"를 보여 주는 값이 중심위치의 척도입니다.

##### 3-1. 모평균

모평균은 모집단 전체의 평균입니다.

공식은 다음과 같습니다.

`mu = (모든 값의 합) / (전체 개수 N)`

예를 들어 어떤 반 학생 5명의 점수가 60, 70, 80, 90, 100이라면 모평균은

`(60 + 70 + 80 + 90 + 100) / 5 = 80`

입니다.

즉, 모평균은 전체 집단의 중심을 나타내는 가장 대표적인 모수입니다.

##### 3-2. 중심 위치를 표현하는 통계량

###### 산술평균

가장 흔히 말하는 평균입니다.

`산술평균 = 값의 합 / 개수`

계산이 쉽고 많이 쓰이지만, 아주 큰 값이나 아주 작은 값의 영향을 많이 받을 수 있습니다.

###### 중위수

값을 크기순으로 놓았을 때 가운데 오는 값입니다.

예를 들어 10, 20, 30, 1000의 산술평균은 265이지만,  
중위수는 25입니다.

그래서 중위수는 `극단값의 영향을 덜 받는 대표값`입니다.

###### 최빈수

가장 자주 나타나는 값입니다.

예를 들어 70, 80, 80, 80, 90이라면 최빈수는 80입니다.

정성적 데이터에서도 자주 쓰입니다.

- 가장 많이 팔린 색상
- 가장 많이 선택된 등급

###### 범위의 중간

가장 큰 값과 가장 작은 값의 중간입니다.

`범위의 중간 = (최댓값 + 최솟값) / 2`

계산은 쉽지만, 중간 값들의 정보를 충분히 반영하지 못합니다.

###### 기하평균

비율이 계속 곱해지는 데이터에서 많이 씁니다.

예를 들어 어떤 값이 해마다 `2배`, `3배`처럼 변할 때 산술평균보다 기하평균이 더 적절할 수 있습니다.

공식은

`기하평균 = (모든 값을 곱한 것)^(1/n)`

입니다.

###### 조화평균

속도, 단가, 단위당 시간처럼 `나누기 형태`의 값에서 자주 씁니다.

예를 들어 같은 거리를 서로 다른 속도로 이동했을 때 평균 속도를 구할 때 사용할 수 있습니다.

조화평균은 작은 값의 영향을 더 크게 받는 편입니다.

#### 4. 산포의 척도

평균만으로는 데이터의 모습을 다 알 수 없습니다.  
평균이 같아도 값들이 서로 바짝 붙어 있을 수도 있고, 멀리 퍼져 있을 수도 있습니다.

이렇게 데이터가 얼마나 흩어져 있는지를 나타내는 값이 `산포의 척도`입니다.

##### 4-1. 모집단의 산포 척도

###### 모분산

모분산은 각 값이 평균에서 얼마나 떨어져 있는지를 제곱해서 평균 낸 값입니다.

왜 제곱하느냐면,  
평균보다 큰 값과 작은 값을 그냥 더하면 서로 상쇄되어 버리기 때문입니다.

공식은 다음과 같습니다.

`sigma^2 = [(각 값 - 모평균)^2의 합] / N`

###### 모표준편차

모표준편차는 모분산에 제곱근을 씌운 값입니다.

`sigma = sqrt(sigma^2)`

분산은 제곱 단위라 직관적으로 보기 불편할 수 있어서,  
표준편차를 더 자주 사용합니다.

예를 들어 키의 표준편차가 크면 학생들 키 차이가 큰 것이고,  
작으면 비슷비슷하다는 뜻입니다.

##### 4-2. 산포를 표현하는 통계량

###### 제곱합

제곱합은 평균으로부터 떨어진 정도를 제곱해서 모두 더한 값입니다.

`SS = Σ(x - 평균)^2`

분산과 분산분석의 출발점이 되는 아주 중요한 값입니다.

###### 평균제곱

평균제곱은 제곱합을 자유도로 나눈 값입니다.

`MS = SS / df`

분산분석에서 자주 등장합니다.

###### 자유도

자유도는 `마음대로 움직일 수 있는 정보의 수`라고 생각하면 됩니다.

예를 들어 평균이 이미 정해져 있으면 마지막 값 하나는 자동으로 결정되는 부분이 생깁니다.  
그래서 표본분산에서는 보통 `n-1`을 사용합니다.

###### 표본표준편차

표본으로 계산한 표준편차입니다.

`s = sqrt[Σ(x - x-bar)^2 / (n - 1)]`

모집단 전체가 아니라 표본으로 계산할 때는 보통 `n`이 아니라 `n-1`로 나눕니다.

###### 변동계수

변동계수는 평균에 비해 산포가 얼마나 큰지를 보는 값입니다.

`CV = s / x-bar`

필요하면 백분율로

`CV(%) = (s / x-bar) × 100`

처럼 쓰기도 합니다.

평균 크기가 다른 두 집단을 비교할 때 특히 유용합니다.

###### 상대분산

상대분산은 분산을 평균의 크기와 비교해서 보는 값입니다.

`상대분산 = s^2 / (x-bar)^2`

이는 변동계수를 제곱한 값과 같은 방향으로 이해하면 됩니다.

###### 범위

범위는 가장 큰 값에서 가장 작은 값을 뺀 값입니다.

`범위 = 최댓값 - 최솟값`

계산은 가장 쉽지만, 중간 값들의 정보는 반영하지 못한다는 한계가 있습니다.

##### 4-3. 왜도와 첨도

###### 왜도

왜도는 데이터가 어느 한쪽으로 기울어져 있는지를 나타냅니다.

- 오른쪽 꼬리가 길면 `양의 왜도`
- 왼쪽 꼬리가 길면 `음의 왜도`

예를 들어 대부분 시험 점수는 높지만 몇 명만 아주 낮으면 왼쪽으로 꼬리가 길 수 있습니다.

###### 첨도

첨도는 데이터가 얼마나 뾰족하거나 평평한지를 나타냅니다.

- 가운데에 값이 몰려 뾰족하면 첨도가 큰 편
- 넓게 퍼져 평평하면 첨도가 작은 편

왜도와 첨도는 데이터 모양을 이해할 때 도움이 됩니다.

#### 한 번에 정리하기

이 절에서 꼭 기억해야 할 핵심은 다음과 같습니다.

- 모수는 전체 집단의 값이고, 통계량은 표본으로 계산한 값입니다.
- 기술통계학은 데이터를 설명하고, 추측 통계학은 일부를 보고 전체를 추정합니다.
- 데이터는 정성적/정량적 데이터로 나뉘고, 각각 다시 세부적으로 분류됩니다.
- 평균은 중심을 보여 주고, 분산과 표준편차는 흩어진 정도를 보여 줍니다.
- 평균만 보면 부족하고, 산포까지 함께 봐야 데이터의 실제 모습을 이해할 수 있습니다.

이 개념들이 익숙해지면 이후에 나오는 확률분포, 검정, 관리도, 공정능력 해석이 훨씬 쉬워집니다.

### 1.2 확률

### 1.3 확률분포

확률분포는 확률변수가 어떤 값을 얼마나 자주 갖는지를 설명하며, 이산형 분포와 연속형 분포로 나누어 이해합니다.

<a id="p1-c2"></a>
## 제2장 검정과 추정

검정과 추정은 표본 정보를 바탕으로 모집단에 대한 판단을 내리는 핵심 절차입니다.

<a id="p1-c2-s1"></a>
### 2.1 검정과 추정의 기초 이론

점추정, 구간추정, 귀무가설, 대립가설, 유의수준, p-value의 관계를 먼저 구조적으로 정리합니다.

<a id="p1-c2-s2"></a>
### 2.2 단일모집단의 검정과 추정

하나의 모집단 평균, 분산, 비율에 대해 신뢰구간을 구하고 가설검정을 수행하는 방법을 다룹니다.

<a id="p1-c2-s3"></a>
### 2.3 두 모집단의 차이의 검정과 추정

두 집단 평균이나 비율 차이를 비교할 때 어떤 검정 절차와 추정 방식을 써야 하는지 정리합니다.

<a id="p1-c2-s4"></a>
### 2.4 계수값 검정과 추정

불량 수, 결점 수, 비율과 같은 계수값 데이터에 적합한 검정과 추정 프레임을 다룹니다.

<a id="p1-c2-s5"></a>
### 2.5 적합도 검정 및 동일성 검정

관측 데이터가 특정 분포를 따르는지, 여러 집단이 동일한 분포를 가지는지를 판정하는 방법을 학습합니다.

## 제3장 상관 및 단순회귀

두 변수 간 관계를 수치로 파악하고 예측하는 기본 도구를 다룹니다.

<a id="p1-c3-s1"></a>
### 3.1 상관 및 단순회귀

상관계수로 선형 관계를 파악하고, 단순회귀식으로 변수 간 영향을 설명하는 기본 구조를 익힙니다.

<a id="p1-c4"></a>
## 제4장 샘플링검사

전수검사가 어려운 상황에서 일부 샘플만으로 lot를 판정하는 방법을 다룹니다.

<a id="p1-c4-s1"></a>
### 4.1 검사(Inspection) 개요

검사의 목적, 전수검사와 샘플링검사의 차이, 품질보증 관점에서 검사의 위치를 정리합니다.

<a id="p1-c4-s2"></a>
### 4.2 샘플링 방법과 샘플링 오차

표본 추출 방식에 따라 어떤 오차가 발생하는지와 샘플링 설계의 기본 원리를 설명합니다.

<a id="p1-c4-s3"></a>
### 4.3 샘플링검사와 OC곡선

OC곡선으로 합격확률을 해석하고 생산자 위험과 소비자 위험을 함께 이해합니다.

<a id="p1-c4-s4"></a>
### 4.4 계량값 샘플링검사

측정값 기반 샘플링검사 절차와 판정 방식을 계량 데이터 관점에서 설명합니다.

<a id="p1-c4-s5"></a>
### 4.5 계수값 샘플링검사

불량 수와 불량률을 기준으로 lot를 판정하는 계수값 샘플링검사를 다룹니다.

<a id="p1-c4-s6"></a>
### 4.6 축차 샘플링검사

검사 진행 중간에 합격, 불합격, 계속검사를 결정하는 축차 샘플링검사의 구조를 정리합니다.

## 제5장 관리도

관리도는 공정이 통계적으로 안정 상태에 있는지를 감시하는 대표 도구입니다.

<a id="p1-c5-s1"></a>
### 5.1 공정모니터링과 관리도 활용

관리도의 목적과 현장 적용 방식, 이상원인 탐지 도구로서의 역할을 설명합니다.

<a id="p1-c5-s2"></a>
### 5.2 계량값 관리도

X-bar, R, s 관리도처럼 연속형 측정값을 사용하는 관리도 종류와 해석을 다룹니다.

<a id="p1-c5-s3"></a>
### 5.3 계수값 관리도

p, np, c, u 관리도처럼 불량수와 결점수를 관리하는 방법을 정리합니다.

<a id="p1-c5-s4"></a>
### 5.4 관리도의 판정 및 공정해석

관리한계 이탈과 이상 패턴을 어떻게 해석하고 공정조치로 연결할지 설명합니다.

<a id="p1-c5-s5"></a>
### 5.5 관리도의 성능 및 수리

관리도의 검출 성능과 관리한계 설정, 오경보와 미검출 문제를 함께 다룹니다.
