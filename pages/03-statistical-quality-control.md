# 제1부 통계적 품질관리

통계적 품질관리는 품질 데이터를 해석하고, 공정 변동을 이해하며, 합리적으로 판정하는 데 필요한 기본 도구를 다룹니다.  
이 파트에서는 확률과 분포, 검정과 추정, 상관과 회귀, 샘플링검사, 관리도를 하나의 흐름으로 연결합니다.

<a id="p1-c1"></a>
## 제1장 확률과 확률분포

품질 데이터를 다루기 위한 가장 기초적인 언어가 확률과 확률분포입니다.

<a id="p1-c1-s1"></a>
### 1.1 모수와 통계량

모수는 모집단의 특성을 나타내는 값이고, 통계량은 표본으로부터 계산한 값으로 모수를 추정하는 데 사용됩니다.

<a id="p1-c1-s2"></a>
### 1.2 확률

확률은 불확실한 사건이 발생할 가능성을 수치화한 개념이며, 이후 검정과 품질 판정의 기반이 됩니다.

<a id="p1-c1-s3"></a>
### 1.3 확률분포

확률분포는 확률변수가 어떤 값을 얼마나 자주 갖는지를 설명하며, 이산형 분포와 연속형 분포로 나누어 이해합니다.

<a id="p1-c2"></a>
## 제2장 검정과 추정

검정과 추정은 표본 정보를 바탕으로 모집단에 대한 판단을 내리는 핵심 절차입니다.

<a id="p1-c2-s1"></a>
### 2.1 검정과 추정의 기초 이론

점추정, 구간추정, 귀무가설, 대립가설, 유의수준, p-value의 관계를 먼저 구조적으로 정리합니다.

<a id="p1-c2-s2"></a>
### 2.2 단일모집단의 검정과 추정

하나의 모집단 평균, 분산, 비율에 대해 신뢰구간을 구하고 가설검정을 수행하는 방법을 다룹니다.

<a id="p1-c2-s3"></a>
### 2.3 두 모집단의 차이의 검정과 추정

두 집단 평균이나 비율 차이를 비교할 때 어떤 검정 절차와 추정 방식을 써야 하는지 정리합니다.

<a id="p1-c2-s4"></a>
### 2.4 계수값 검정과 추정

불량 수, 결점 수, 비율과 같은 계수값 데이터에 적합한 검정과 추정 프레임을 다룹니다.

<a id="p1-c2-s5"></a>
### 2.5 적합도 검정 및 동일성 검정

관측 데이터가 특정 분포를 따르는지, 여러 집단이 동일한 분포를 가지는지를 판정하는 방법을 학습합니다.

<a id="p1-c3"></a>
## 제3장 상관 및 단순회귀

두 변수 간 관계를 수치로 파악하고 예측하는 기본 도구를 다룹니다.

<a id="p1-c3-s1"></a>
### 3.1 상관 및 단순회귀

상관계수로 선형 관계를 파악하고, 단순회귀식으로 변수 간 영향을 설명하는 기본 구조를 익힙니다.

<a id="p1-c4"></a>
## 제4장 샘플링검사

전수검사가 어려운 상황에서 일부 샘플만으로 lot를 판정하는 방법을 다룹니다.

<a id="p1-c4-s1"></a>
### 4.1 검사(Inspection) 개요

검사의 목적, 전수검사와 샘플링검사의 차이, 품질보증 관점에서 검사의 위치를 정리합니다.

<a id="p1-c4-s2"></a>
### 4.2 샘플링 방법과 샘플링 오차

표본 추출 방식에 따라 어떤 오차가 발생하는지와 샘플링 설계의 기본 원리를 설명합니다.

<a id="p1-c4-s3"></a>
### 4.3 샘플링검사와 OC곡선

OC곡선으로 합격확률을 해석하고 생산자 위험과 소비자 위험을 함께 이해합니다.

<a id="p1-c4-s4"></a>
### 4.4 계량값 샘플링검사

측정값 기반 샘플링검사 절차와 판정 방식을 계량 데이터 관점에서 설명합니다.

<a id="p1-c4-s5"></a>
### 4.5 계수값 샘플링검사

불량 수와 불량률을 기준으로 lot를 판정하는 계수값 샘플링검사를 다룹니다.

<a id="p1-c4-s6"></a>
### 4.6 축차 샘플링검사

검사 진행 중간에 합격, 불합격, 계속검사를 결정하는 축차 샘플링검사의 구조를 정리합니다.

<a id="p1-c5"></a>
## 제5장 관리도

관리도는 공정이 통계적으로 안정 상태에 있는지를 감시하는 대표 도구입니다.

<a id="p1-c5-s1"></a>
### 5.1 공정모니터링과 관리도 활용

관리도의 목적과 현장 적용 방식, 이상원인 탐지 도구로서의 역할을 설명합니다.

<a id="p1-c5-s2"></a>
### 5.2 계량값 관리도

X-bar, R, s 관리도처럼 연속형 측정값을 사용하는 관리도 종류와 해석을 다룹니다.

<a id="p1-c5-s3"></a>
### 5.3 계수값 관리도

p, np, c, u 관리도처럼 불량수와 결점수를 관리하는 방법을 정리합니다.

<a id="p1-c5-s4"></a>
### 5.4 관리도의 판정 및 공정해석

관리한계 이탈과 이상 패턴을 어떻게 해석하고 공정조치로 연결할지 설명합니다.

<a id="p1-c5-s5"></a>
### 5.5 관리도의 성능 및 수리

관리도의 검출 성능과 관리한계 설정, 오경보와 미검출 문제를 함께 다룹니다.
