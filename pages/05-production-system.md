# 제4부 생산시스템

생산시스템은 품질, 납기, 원가, 재고, 설비 운영이 하나의 흐름으로 연결되는 운영 체계입니다.  
이 파트에서는 생산전략, 자재관리, 생산계획, 표준작업, 설비보전을 중심으로 시험 범위를 정리합니다.

<a id="p4-c1"></a>
## 제1장 생산전략과 생산시스템

생산 운영의 큰 틀을 이해해야 재고, 일정, 설비, 작업관리의 세부 개념이 연결됩니다.

<a id="p4-c1-s1"></a>
### 1.1 생산시스템의 개념

생산시스템은 자원 투입을 통해 제품과 서비스를 산출하는 전체 흐름으로 이해합니다.

<a id="p4-c1-s2"></a>
### 1.2 생산형태와 설비배치/라인밸런싱

개별생산, 로트생산, 연속생산의 특성과 배치 방식, 라인 균형의 의미를 정리합니다.

<a id="p4-c1-s3"></a>
### 1.3 SCM(공급망관리)

SCM은 공급자부터 고객까지 이어지는 흐름을 통합적으로 관리하는 개념입니다.

<a id="p4-c1-s4"></a>
### 1.4 생산전략과 의사결정론

생산전략은 경쟁우선순위와 자원 제약을 반영해 운영 방향을 선택하는 과정입니다.

<a id="p4-c1-s5"></a>
### 1.5 ERP(전사적 자원관리)와 생산정보관리

ERP는 생산, 자재, 구매, 재고, 회계를 연결해 정보 흐름을 통합하는 시스템입니다.

<a id="p4-c1-s6"></a>
### 1.6 수요예측

수요예측은 생산계획과 재고계획의 출발점이며 정성적 방법과 정량적 방법으로 나눌 수 있습니다.

<a id="p4-c1-s7"></a>
### 1.7 제품조합

제약된 자원 내에서 이익과 수요를 고려해 어떤 제품을 얼마나 생산할지 결정하는 문제를 다룹니다.

<a id="p4-c2"></a>
## 제2장 자재관리 전략

자재관리 전략은 재고를 줄이면서도 생산 차질을 막는 균형을 찾는 영역입니다.

<a id="p4-c2-s1"></a>
### 2.1 자재관리와 MRP(자재소요량 계획)

MRP는 생산계획과 BOM을 바탕으로 자재 필요시점과 수량을 계산하는 시스템입니다.

<a id="p4-c2-s2"></a>
### 2.2 재고관리

재고관리에서는 주문량, 안전재고, 발주점 등 핵심 개념을 통해 수요와 공급 변동에 대응합니다.

<a id="p4-c2-s3"></a>
### 2.3 외주 및 구매관리

외주와 구매는 원가뿐 아니라 품질, 납기, 공급 안정성까지 함께 고려해야 하는 관리 대상입니다.

<a id="p4-c2-s4"></a>
### 2.4 적시생산시스템(JIT)

JIT는 필요한 것을 필요한 시점에 필요한 양만 생산하는 흐름 중심 생산 방식입니다.

<a id="p4-c3"></a>
## 제3장 생산계획 수립

생산계획 수립은 수요를 실제 작업 일정과 자원 배분으로 전환하는 과정입니다.

<a id="p4-c3-s1"></a>
### 3.1 생산계획 및 통제

생산계획과 통제는 기준 계획 수립과 실적 비교, 차이 조정의 반복 구조로 이해할 수 있습니다.

<a id="p4-c3-s2"></a>
### 3.2 작업순위결정방법

SPT, EDD 등 우선순위 규칙을 이용해 납기와 대기시간을 조정하는 방법을 정리합니다.

<a id="p4-c3-s3"></a>
### 3.3 프로젝트 일정관리 및 PERT/CPM

프로젝트 일정관리에서는 네트워크 기법을 활용해 주경로와 여유시간을 해석합니다.

<a id="p4-c4"></a>
## 제4장 표준작업 관리

표준작업 관리는 공정과 작업을 분석해 가장 합리적인 작업 방법과 시간을 설정하는 영역입니다.

<a id="p4-c4-s1"></a>
### 4.1 공정분석과 작업분석

공정 전체 흐름과 세부 작업을 나누어 분석함으로써 낭비 제거와 개선 포인트를 찾습니다.

<a id="p4-c4-s2"></a>
### 4.2 동작분석

작업자의 동작을 세분화해 비효율을 줄이고 표준작업을 설계하는 기초 방법입니다.

<a id="p4-c4-s3"></a>
### 4.3 표준시간과 작업측정

표준시간은 정상적인 작업 조건에서 필요한 기준 시간을 의미하며 작업측정으로 산정합니다.

<a id="p4-c4-s4"></a>
### 4.4 생산성관리 및 작업측정

생산성 지표와 작업측정을 연결해 현장의 개선 효과를 정량적으로 파악합니다.

<a id="p4-c5"></a>
## 제5장 설비보전

설비보전은 설비 고장을 줄이고 가동 안정성을 높이는 운영의 핵심입니다.

<a id="p4-c5-s1"></a>
### 5.1 설비보전의 종류

사후보전, 예방보전, 예지보전 등 보전 방식의 차이와 적용 상황을 구분합니다.

<a id="p4-c5-s2"></a>
### 5.2 TPM(종합적설비관리)

TPM은 생산부서와 보전부서가 함께 설비 효율 극대화를 목표로 운영하는 전사적 활동입니다.
