# 7. 품질경영기사 실기와 답안 작성

실기는 필기 지식을 다시 묻는 시험이지만, 평가 방식은 다릅니다.  
객관식처럼 정답을 고르는 것이 아니라, 주어진 정보를 구조화해서 계산하고 설명하는 능력을 직접 보여줘야 합니다.

## 이 장에서 다루는 것

- 실기 문제를 읽는 순서와 답안 설계 방법
- 계산형, 정의형, 비교형, 개선제안형 답안 구조
- 부분점수를 받기 쉬운 서술 습관
- 자주 나오는 실수와 검산 체크리스트

## 실기 답안의 기본 원칙

### 1. 결론부터 씁니다

채점자는 긴 사고 과정보다 명확한 결론을 먼저 찾습니다.  
따라서 답안은 보통 `결론 -> 근거 -> 계산 또는 설명 -> 정리` 순서가 안정적입니다.

### 2. 용어를 정확히 구분합니다

실기에서는 비슷한 용어를 섞는 순간 감점 위험이 큽니다.

- 관리한계와 규격한계
- 산포와 편차
- 공정 안정과 공정 능력
- 신뢰도와 가용도

### 3. 계산식은 변수 의미를 드러내게 씁니다

숫자만 대입하면 검산이 어렵고, 단위 오류를 놓치기 쉽습니다.  
가능하면 `공식 -> 대입 -> 계산 결과 -> 해석` 순서로 작성합니다.

## 답안 템플릿

### 정의형

`A란 무엇인가?` 유형에서는 다음 구조가 안정적입니다.

- 정의 한 문장
- 목적 또는 특징 한 문장
- 필요하면 비교 포인트 한 문장

### 비교형

`A와 B를 비교하라` 유형에서는 비교 축을 먼저 세워야 합니다.

- 목적
- 적용 상황
- 장점
- 한계

### 개선제안형

현상만 쓰지 말고 원인과 조치를 연결해야 점수가 잘 나옵니다.

- 현재 문제 요약
- 원인 가설 또는 분석 포인트
- 개선 조치
- 기대 효과

## 자주 틀리는 포인트

- 계산 결과는 맞았지만 해석 문장을 쓰지 않는 경우
- 표나 그래프를 읽고도 결론을 명시하지 않는 경우
- 서술형 답안에서 추상적인 표현만 반복하는 경우
- 시간 부족으로 뒤 문제를 비워 두는 경우

## 집필 가이드

- 과목별 핵심 서술 문장을 묶은 실기용 표현집을 후속 추가합니다.
- 계산 문제는 검산 포인트와 오답 패턴을 함께 정리합니다.
- 실제 답안지 분량을 감안한 문장 길이 예시를 포함합니다.
